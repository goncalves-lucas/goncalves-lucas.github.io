Mercadin

Sistema web de gestão para mercado: produtos, estoque, compras, fornecedores e funcionários, com login e controle de acesso.

Problema

Um mercado precisa saber o que tem em estoque, o que está perto de vencer, o que foi comprado e de qual fornecedor. Quando essas informações ficam espalhadas, é fácil perder produto por validade e perder o controle do que foi comprado.

Além disso, nem todo mundo na equipe deve poder alterar tudo: é preciso separar quem só consulta de quem administra.

O que eu fiz

Desenvolvi o Mercadin completo: uma API própria e uma interface web conectada a ela. Pela interface é possível cadastrar e consultar produtos, lotes de estoque, compras, fornecedores e funcionários, com um painel inicial que destaca o que precisa de atenção.

Como eu fiz

Ferramentas

  • React 19
  • Vite
  • React Router
  • Node.js
  • Express 5
  • TypeScript
  • Prisma 7
  • MySQL / MariaDB
  • Zod
  • JWT
  • bcryptjs

API (back-end)

  • Organizada em camadas: rotas, controllers, services e schemas de validação.
  • Autenticação por login com token JWT e senhas armazenadas com hash (bcrypt).
  • Três perfis de usuário (admin, user e cliente): qualquer usuário autenticado consulta; criar, alterar e excluir é restrito ao administrador.
  • Validação dos dados de entrada com Zod antes de chegar ao banco.
  • Listagens com paginação.
  • Ao registrar uma compra, o sistema cria automaticamente o lote correspondente no estoque, dentro de uma transação, para que as duas informações não fiquem inconsistentes.

Banco de dados

Modelado com Prisma e versionado por migration. Seis tabelas: usuários, produtos, estoque, compras, fornecedores e funcionários, ligadas por relações (um produto tem lotes de estoque e compras; uma compra pode ter um fornecedor e gera um lote de estoque).

Interface (front-end)

  • Tela de login e rotas protegidas: só entra quem estiver autenticado.
  • Dashboard com o total de produtos e fornecedores, os itens mais próximos do vencimento (vencidos ou a até 30 dias), os de menor quantidade em estoque e as compras mais recentes.
  • Telas de cadastro, edição e exclusão para produtos, estoque, compras, fornecedores e funcionários, com confirmação antes de excluir e máscaras nos campos de entrada.
